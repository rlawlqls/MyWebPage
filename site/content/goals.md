저의 목표는 인공지능을 활용해 실제 문제를 발견하고, 데이터를 기반으로 해결책을 설계하여 서비스나 로봇으로 구현할 수 있는 개발자가 되는 것입니다.

## 관심 분야와 선택 이유

저의 관심 분야는 **인공지능, 금융권 IT, 로보틱스**입니다.

인공지능을 활용해 기존 방식으로 해결하기 어려운 문제를 분석하고 새로운 가치를 만드는 과정에 관심이 있습니다. 특히 많은 사람의 일상과 밀접하게 연결된 금융 서비스를 더 편리하고 안전하게 만드는 기술을 공부하고 싶습니다.

또한 인공지능이 화면 속 서비스에만 머무르지 않고 로봇과 결합해 현실의 문제를 직접 해결하는 과정에도 관심이 있어 로보틱스를 함께 공부하고 있습니다.

## 2026 인공지능 특화교육 수강

2026년 11월 2일부터 11월 12일까지 진행되는 인공지능 특화교육을 수강하고 있습니다.

이 교육을 통해 인공지능 기초와 생성형 AI 기반 프로그래밍에 대한 이해를 높이고, 실무 중심의 코딩 역량을 강화하고 있습니다. 궁극적으로는 인공지능을 활용한 문제 해결 능력과 기술 경쟁력을 갖춘 개발자로 성장하는 것이 목표입니다.

## 학습 계획

1. **Python과 생성형 AI 활용**
   Advanced Python을 학습하고 생성형 AI를 활용해 코드를 작성한 뒤, 실행 결과와 오류를 직접 분석합니다.

2. **딥러닝 기초와 정보검색**
   딥러닝의 기본 원리를 이해하고 정보검색 실습을 통해 모델이 데이터를 처리하는 과정을 학습합니다.

3. **전이학습과 컴퓨터 비전**
   적은 데이터로도 모델을 활용할 수 있는 전이학습을 익히고, 이미지 데이터를 분석하는 컴퓨터 비전 실습을 진행합니다.

4. **로봇 학습으로 확장**
   물리 시뮬레이션 환경을 구축하고 학습 데이터를 수집하여 인공지능 모델을 로봇의 작업 수행과 연결하는 방법을 공부합니다.

## 현재 배우고 있는 내용

현재 다음 내용을 학습하고 있습니다.

- Advanced Python Programming
- 생성형 AI를 활용한 코딩
- 딥러닝 프로그래밍 기초
- 딥러닝 기반 정보검색
- 저자원 전이학습
- 컴퓨터 비전
- 물리 시뮬레이션과 로봇 학습 데이터 수집

## 앞으로의 계획

교육에서 배운 내용을 복습하고 실습 코드를 다시 구현하면서 각 기술에 대한 이해를 높일 계획입니다. 이후 금융 서비스 또는 로보틱스와 관련된 문제를 선정해 데이터 준비, 모델 학습, 서비스나 하드웨어 연동까지 포함한 인공지능 프로젝트를 수행하고 포트폴리오에 추가하고자 합니다.
