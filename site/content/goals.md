제 학습 목표는 **사용자의 문제를 발견하고, 데이터를 수집하고, AI 모델을 만들어, 웹이나 하드웨어로 제공하는 전 과정**을 스스로 완성할 수 있는 개발자가 되는 것입니다.

## 관심 분야와 선택 이유

관심 분야는 **생성형 AI, 딥러닝, 컴퓨터 비전, Physical AI**입니다. 단순히 모델의 정확도를 높이는 데서 끝나지 않고, 인공지능이 웹 서비스나 로봇과 연결되어 누군가의 문제를 해결하는 과정을 직접 만들고 싶어 이 분야를 선택했습니다. Speech Bridge에서 음성 데이터를 학습한 모델을 Arduino와 웹에 연결하고, Market Mate AI에서 Vision API와 Gemini API를 서비스에 적용한 경험이 이 관심을 더욱 구체화했습니다.

## 2026 인공지능 특화교육 수강 중

**수강 기간:** 2026년 11월 2일 - 11월 12일 · 현재 수강 중

인공지능 기초교육과 생성형 AI 기반 프로그래밍 특화교육을 통해 인공지능에 대한 이해를 높이고, 실무 중심 코딩 역량을 강화하기 위해 참여하고 있습니다. 수강생으로서 이론을 정리하고 실습 코드를 직접 실행하며, 각 기술이 실제 문제에 어떻게 적용되는지 확인하고 있습니다.

## 교육에 맞춘 학습 계획

1. **Python과 생성형 AI 코딩:** Advanced Python 문법을 복습하고, 생성형 AI의 제안을 그대로 사용하는 데서 그치지 않고 실행 결과와 오류 원인을 직접 확인합니다.
2. **딥러닝 핵심 개념:** 딥러닝 프로그래밍 기초를 익힌 뒤 정보검색, 전이학습, 컴퓨터 비전 실습으로 적용 범위를 넓힙니다.
3. **로봇 학습으로 확장:** 물리 시뮬레이션 환경 구축과 학습 데이터 획득 과정을 이해하고, 모델을 로봇의 task 수행과 연결하는 방법을 학습합니다.
4. **학습 기록:** 매 수업의 실습 코드와 새로 배운 개념, 오류 해결 과정을 GitHub README와 학습 노트로 정리합니다.

## 현재 배우는 내용과 다음 목표

현재 Advanced Python Programming, 생성형 AI를 활용한 코딩, 딥러닝 프로그래밍 기초, 딥러닝 기반 정보검색, 저자원 전이학습, 컴퓨터 비전, 로봇 학습을 위한 물리 시뮬레이션과 데이터 획득을 공부하고 있습니다. 짧은 교육 기간 때문에 모든 주제를 깊게 다루기 어렵다는 한계가 있으므로, 수료 후에는 각 실습을 다시 구현하고 결과를 비교하며 부족한 부분을 보완할 계획입니다.

교육에서 익힌 내용을 바탕으로 **앞으로 인공지능 관련 프로젝트를 수행할 예정**입니다. 특히 컴퓨터 비전이나 로봇 학습 중 하나를 선택해 데이터 준비, 모델 학습, 서비스 또는 하드웨어 연동까지 완성한 프로젝트를 포트폴리오에 추가하는 것이 다음 목표입니다.
