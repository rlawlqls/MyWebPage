## 문제와 목표

FTD 환자의 짧거나 불완전한 발화를 분류하고 완전한 문장으로 복원해 화면에 보여 주는 의사소통 보조 서비스를 목표로 했습니다. 모델만 만드는 것이 아니라 사용자가 결과를 확인할 수 있도록 Arduino와 웹 인터페이스까지 연결했습니다.

## 제가 맡은 역할과 과정

- 프로젝트 주제 선정과 문제 상황 분석에 참여했습니다.
- 필요한 음성 데이터를 직접 녹음하고 라벨링했습니다.
- 데이터 라벨과 window 크기를 바꾸어 여러 학습 결과를 비교했습니다.
- Arduino, 머신러닝 모델, 웹 인터페이스를 연결하고 영어 발표에 참여했습니다.

직접 수집한 데이터를 선택한 이유는 실제 사용 환경에 가까운 발화를 바탕으로 모델의 동작을 확인하기 위해서였습니다. 분류 결과가 화면의 복원 문장으로 이어지게 만들어 기술이 사용자에게 전달되는 전체 흐름을 확인했습니다.

## 결과와 다음 개선 방향

불완전한 발화가 입력되면 분류 결과에 맞는 완전한 문장이 화면에 나타나는 프로토타입을 완성했습니다. 데이터 수가 적고 다양한 화자를 충분히 반영하지 못한 한계가 있어, 다음에는 화자별 데이터를 늘리고 오분류 사례를 유형별로 기록해 모델과 인터페이스를 함께 개선하고자 합니다.
