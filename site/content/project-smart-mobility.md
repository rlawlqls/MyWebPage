**기간:** 2024년 - 2025년 1월 · 수료  
**교육:** 스마트 모빌리티 전문가 양성과정

## 학습 목표

HTML, CSS, JavaScript의 역할을 이해하고, 배운 내용을 실제로 동작하는 모빌리티 웹 화면에 적용하는 것이 목표였습니다.

## 수행 과정과 결과

웹 페이지의 구조와 스타일, 기본 상호작용을 학습한 뒤 제주도 이동 정보를 보여 주는 내비게이션 프로젝트를 진행했습니다. 처음에는 기능을 한 번에 만들기보다 화면 구조, 스타일, 동작을 나누어 구현하며 오류의 위치를 확인했습니다.

웹 기술의 기초가 이후 API를 연결한 Market Mate AI와 여러 포트폴리오 화면을 만드는 기반이 되었습니다. 다음에는 경로 검색 결과와 지도 데이터가 실제로 연결되는 형태로 기능을 확장하고 싶습니다.
